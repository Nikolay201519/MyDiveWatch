# 🤿 MyDiveWatch — Дайв-компьютер для Wear OS

![Wear OS](https://shields.io)

![Jetpack Compose](https://shields.io)
![Algorithm](https://shields.io)

**MyDiveWatch** — это нативное автономное приложение-симулятор дайв-компьютера для умных часов на базе **Wear OS** (Samsung Galaxy Watch 4 / 5 / 6 / 7 / 8 / 9 / Ultra и другие модели), написанное на Kotlin с использованием Jetpack Compose.

---

## ⚡ Ключевые функции

| Функция | Описание |
| :--- | :--- |
| 🧠 **Алгоритм Бюльмана ZHL-16C** | Расчет насыщения 16 групп тканей в реальном времени, бездекомпрессионного предела (**NDL**) и обязательных декомпрессионных остановок (**STOP**). |
| 🧪 **Воздух и Nitrox (EAN22–40)** | Быстрое переключение смеси прямо с экрана часов с автоматическим расчетом **MOD** и текущего парциального давления кислорода (**ppO₂**). |
| 🌊 **Глубиномер и датчики** | Считывание давления с встроенного барометра с калибровкой на поверхности, секундомер погружения и мониторинг пульса. |
| 🚨 **Цветовая индикация** | Мгновенная смена фона экрана на красный при превышении **MOD** и на оранжевый при необходимости декомпрессионной остановки. |

## 📲 Как скачать и установить на часы

1. **Скачайте APK:** нажмите на файл **`app-debug (1).apk`** в списке файлов выше (или в разделе **Releases**) и нажмите кнопку **Download**.
2. **Включите отладку на часах:**
   * Откройте *Настройки → О часах → Сведения о ПО* и нажмите **7 раз** на *Номер сборки*.
   * Вернитесь в *Настройки → Параметры разработчика* и включите **Отладка по ADB** и **Беспроводная отладка**.
3. **Установите через телефон:**
   * Подключите телефон и часы к одной сети Wi-Fi.
   * Откройте на Android-смартфоне приложение **Bugjaeger** или **GeminiMan WearOS Manager**, подключитесь по IP-адресу и порту часов и установите скачанный `.apk`.
4. **Сохраните заряд:** после установки обязательно выключите *Беспроводную отладку* на часах.

## ⚠️ Важное предупреждение (Disclaimer)

> **ВНИМАНИЕ:** Приложение создано исключительно в **учебных, ознакомительных и тренировочных целях** (для тестов на суше или в бассейне). Обычные версии умных часов (5ATM, кроме специализированных версий вроде Galaxy Watch Ultra) не предназначены для погружений под давлением на глубину. **Никогда не используйте данное ПО в качестве основного прибора при реальном дайвинге на открытой воде.**
